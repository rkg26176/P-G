# Telegram Automation Bot

## Installation & Run

1. **Python लाइब्रेरी इंस्टॉल करें:**
   `pip install -r requirements.txt`

2. **Playwright Chromium ब्राउज़र और Linux Dependencies इंस्टॉल करें:**
   `playwright install chromium`
   `playwright install-deps chromium`

3. **बॉट चालू करें:**
   `python bot.py`
